## 模型改进
本文在YOLO11n基础上提出3个自定义模块，用于提升多尺度特征学习与微小病害病灶检测能力：

1. **GMSEC（分组多尺度高效卷积）**
部署于骨干网络末端，采用并行多内核分组卷积，在较低计算开销下增强多尺度特征提取。

2. **MAFPN（多尺度聚合特征金字塔网络）**
跨尺度特征聚合模块，融合多层级特征，缩小不同层之间的语义间隙，强化跨尺度特征交互。

3. **P2BFPN（P2增强特征金字塔网络）**
借助SPDConv无损下采样复用低层P2特征，**不新增检测头**，提升微小、模糊病害病灶检测效果。

> 辅助组件：
> - **SPDConv（空间‑深度无损下采样）**：相比传统步长卷积，最大程度保留空间细节信息。
> - **CSP‑OmniKernel**：结合CSP结构与全向核，捕获多尺度上下文特征信息。

## 数据集
- **图像总数**：4832张多源番茄叶片图像
- **类别**：10类（9类病害 + 健康叶片）
- **类别列表**：`Bacterial_Spot`, `Early_Blight`, `Healthy`, `Late_Blight`, `Leaf_Mold`, `Leaf_Miner`, `Mosaic_Virus`, `Septoria_Leaf_Spot`, `Spider_Mites`, `Yellow_Leaf_Curl_Virus`
- **数据构成**
  - 3361张田间实景图像：采集自厦门苗来园种植基地（2025‑03 ~ 2026‑02，覆盖2个完整番茄生长周期）
  - 1471张公开样本：取自PlantVillage公开数据集
- **标注格式**：YOLO格式病灶边界框标注
- **数据集划分**：训练集 / 验证集 / 测试集 = 7 : 2 : 1
- **数据集下载**：https://zenodo.org/records/23132682?preview=1
